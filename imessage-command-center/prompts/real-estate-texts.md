# Texts you can send

Send these from your iPhone, in the Command Center group, not in a client's thread.

Each one is a request. The bot replies with a plan and an id. Nothing is saved, sent, or booked until you answer with that id:

```
YES a1b2c3d4
```

or

```
👍 a1b2c3d4
```

`NO a1b2c3d4` cancels it. The id in the examples below is a sample. Use the id in the reply you actually get.

The bot will not invent a price. If it cannot see a comp source, it will say so. An offer it writes is a draft until you approve a second text that names who receives it.

## Comps

```
Pull comps for 418 West Pine Street. Use only a source I have connected. If you cannot see one, say so. Do not email anyone.
```

## Offer draft

```
Draft a cash offer for 418 West Pine Street at the price I tell you next. Leave the draft in this chat. Do not send it.
```

Then, only if the draft is right:

```
Send this exact draft to the listing agent at +15555550123. Do not change a word. Do not copy anyone else.
```

That second text still waits for its own YES.

## Buyers

```
Who on my buyer list asked for a 3-bed under $400,000? Read only. Do not text them.
```

```
Draft a note to the buyers who match 418 West Pine. Show it here. Do not send it.
```

## Pipeline

```
Add 418 West Pine Street to my pipeline. Status: offer. Next step: call the listing agent tomorrow. Do not email anyone.
```

```
What is the next step on 418 West Pine?
```

## Schedule

```
What is on my calendar tomorrow between 9 and 1? Read only.
```

```
Draft a calendar hold for a walkthrough at 418 West Pine on Tuesday at 10. Do not send the invite until I YES the time and the guests.
```

## Travel

```
Find two flights next Thursday morning into the city for 418 West Pine, and two hotels near the property. Do not buy anything. Do not put a card down.
```

A booking is a separate text, and only after a connector shows you a real confirmation. The bot is not allowed to invent a confirmation code.

## Team

```
Draft a Slack note to the acquisitions channel: I am walking 418 West Pine Tuesday at 10. Show it here. Do not post it.
```

## CRM

```
What did we last log on 418 West Pine in the CRM? Read only.
```

```
Update the CRM record for 418 West Pine to status Offer, next step call the listing agent. Do not email the owner.
```

If no CRM is connected, the bot uses the local pipeline list and says that is what it used.

## A 20-line to-do list

Send the list in one text. The approval ask repeats every line. One YES saves those lines and does not do them.

```
Save this to-do list and do not start any of them:
1. Order the inspection for 418 West Pine
2. Call the listing agent
3. Confirm earnest money
4. Text my buyer list a draft, not a send
5. Pull insurance quotes
6. Check the sewer scope
7. Ask title for a lien search
8. Book the Tuesday walkthrough as a draft
9. Photograph the basement
10. Get the rent roll
11. Verify the zoning with the city
12. Price the roof
13. Price the HVAC
14. Send the proof-of-funds list to myself only
15. Update the pipeline status
16. Add the lockbox code to my notes
17. Remind me to walk the alley
18. Draft the assignment clause
19. List the repairs over $1,000
20. Set a follow-up for Friday
```

Mark one done later:

```
Mark "Order the inspection for 418 West Pine" done.
```

## What not to text

- A client's thread. Commands stay in the Command Center group.
- "Send the offer" with no address and no recipient. You will get a question, not a guess.
- A wire instruction, a password, or a card number. The bot is told to refuse those.
